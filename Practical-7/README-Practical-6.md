# Practical 6 local run instructions

1. Open the Practical-6 folder in Visual Studio Code.
2. Start a local web server using the Live Server extension (right-click home.html and select Open with Live Server).
3. Navigate to Home, Events, or Profile.
4. Use each page's search box, filter, and sort menu. Use Previous and Next to browse five records per page.
5. If data does not load, confirm the server is running and that events.json, students.json, and faqs.json are in the same folder as the HTML pages.

The pages use ES modules and Fetch API. Opening the HTML files directly with a file:// URL may be blocked by browser security rules.
