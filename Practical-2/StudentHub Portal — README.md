# StudentHub Portal

## Project Overview

**StudentHub** is a web-based student portal designed to provide students with easy access to important academic and campus-related information through a single platform.

This project is developed as a semester-long Web Development project. The initial practical focuses on requirement analysis, sitemap design, wireframing, project structure, and GitHub setup.

---

## Problem Definition

Students often need to visit different sources to access information such as fees, timetable, attendance, faculty details, study materials, placements, and campus information.

StudentHub aims to provide these facilities in one organized and user-friendly web portal.

---

## Project Objectives

- Provide a centralized student information portal.
- Organize academic and campus information.
- Make navigation simple and user-friendly.
- Create a structured and maintainable web project.
- Follow proper Git and GitHub version control practices.

## Page Navigation

Navigation between pages will be managed using HTML hyperlinks (`<a>` tags).

Example:

```html
<a href="attendance.html">Attendance</a>
```

A common navigation bar will be maintained across the main pages so that users can easily move between different sections of StudentHub.

## GitHub Version Control

Git and GitHub will be used to maintain the project and track changes after each practical.

Basic workflow:

```bash
git add .
git commit -m "Completed Practical 1"
git push origin main
```

Each practical will have a meaningful commit message so that the development history can be tracked easily.

Example:

```text
Practical 1 - Project Setup and Wireframe
Practical 2 - Homepage Development
Practical 3 - Student Module
Practical 4 - Academic Module
```
